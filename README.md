# 🎬 TMDB Movies — Flutter App

TMDB Movies is a clean and modern Flutter application that displays trending, now-playing, and searched movies using **The Movie Database (TMDB) API**.  
The app also includes a **bookmark system with offline caching**, allowing users to save movies and view them later without internet.

---

## 🚀 Features

### 🎞 Movie Listing
- Trending Movies (Daily)
- Now Playing Movies
- Search Movies

### 📑 Movie Details
- Movie poster, description, release date, runtime, and revenue
- Bookmark toggle (save/remove)

### ⭐ Bookmarks with Offline Support
- Saved movies persist locally (Hive)
- Poster images stored offline using cache manager
- Bookmark screen refreshes without using setState()

### ⚡ Tech Highlights
- Flutter (Material UI)
- Provider + ChangeNotifier (State Management)
- Dio (Networking)
- Hive (Local storage DB)
- Cached Network Image
- Flutter Cache Manager
- Clean MVVM Architecture
